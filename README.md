این پروژه شامل دو تسک الگوریتمی ساده در پایتون است.

## محتویات

- **Task 1**: طول بزرگ‌ترین زیررشته بدون تکرار
- **Task 2**: بررسی چهار تا ۱ پشت سر هم (با در نظر گرفتن چرخش)

---

## Task 1: طول بزرگ‌ترین زیررشته بدون تکرار

### توضیحات
این برنامه طول بزرگترین زیررشته‌ای را که هیچ کاراکتری در آن تکرار نشده است محاسبه می‌کند.

### مثال
برای رشته `ABCABCFKAB`:
- `ABC` دارای طول ۳
- `ABCFK` دارای طول ۵ (بزرگترین)
- `AB` دارای طول ۲

خروجی: `5`

### نحوه اجرا

```bash
python task1.py
```

### استفاده در کد

```python
from task1 import longest_substring_without_repetition

result = longest_substring_without_repetition("ABCABCFKAB")
print(result)  # خروجی: 5
```

---

## Task 2: بررسی چهار تا ۱ پشت سر هم (چرخشی)

### توضیحات
این برنامه بررسی می‌کند که آیا در یک رشته باینری، چهار تا عدد ۱ پشت سر هم وجود دارد یا خیر.

**نکته مهم**: رشته به صورت چرخشی در نظر گرفته می‌شود، یعنی آخر رشته به اول رشته متصل است.

### مثال
برای رشته `1010111`:
- سه تا ۱ در انتها: `111`
- یک ۱ در ابتدا: `1`
- چون رشته چرخشی است: `1` + `111` = `1111` ✓

خروجی: `True`

### نحوه اجرا

```bash
python task2.py
```

### استفاده در کد

```python
from task2 import has_four_consecutive_ones

result = has_four_consecutive_ones("1010111")
print(result)  # خروجی: True
```
